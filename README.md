# 📚 Library Management System

A desktop Library Management System built with Python and CustomTkinter.

## Features

- Add books
- Edit book information
- Delete books
- Borrow books
- Return books
- Search books
- Sort by:
  - Title
  - Author
  - Year
  - Pages
  - Availability
- Persistent JSON storage

## Technologies

- Python 3.14
- CustomTkinter
- JSON
